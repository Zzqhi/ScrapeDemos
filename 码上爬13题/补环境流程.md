# 码上爬13题 — 补环境流程

## 整体架构

```
main.py (Python 请求调度)
   │
   ├── 调用 sign_wrapper.cjs (Node.js 签名桥接)
   │       │
   │       ├── 加载 PcSign.js (含补环境代码 + 网站原始加密逻辑)
   │       ├── 注入 browser_env.json (多套浏览器指纹)
   │       ├── 注入 cookie
   │       └── 调用 PcSign.sign({page, t}) → 输出 h5 签名
   │
   └── 携带 h5 签名发起 POST 请求 → 获取数据
```

## 文件说明

| 文件 | 作用 |
|------|------|
| `PcSign.js` | 前半部分：手工补的浏览器环境；后半部分：网站原始的 Sign 加密类（混淆后的） |
| `sign_wrapper.cjs` | Node.js 入口，负责加载 PcSign.js、注入运行时参数、调用签名并输出结果 |
| `browser_env.json` | 多套浏览器指纹配置（Windows / Mac），用于轮换 |
| `main.py` | Python 请求端，循环 20 页，每页调用 Node 生成签名后发请求 |

## 补环境详细流程

### 1. 全局对象挂载

PcSign.js 开头将 Node.js 的 `global` 映射为 `window`，让网站 JS 能通过 `window.xxx` 访问各种浏览器 API：

```js
var window = global;
```

### 2. Proxy 调试代理

定义 `createProxy()` 工具函数，用 ES6 Proxy 包装每个伪造对象。所有属性的 `get`/`set`/`getOwnPropertyDescriptor` 操作都会打印日志，便于定位网站 JS 访问了哪些属性：

```js
function createProxy(name, target = {}) {
    return new Proxy(target, {
        get(obj, prop) { console.log(`[Proxy ${name}] get -> ${String(prop)}`); ... },
        set(obj, prop, value) { console.log(`[Proxy ${name}] set -> ${String(prop)}`); ... },
        ...
    });
}
```

> **作用**：逆向初期用 Proxy 日志快速发现缺失属性，按报错逐个补齐。

### 3. document 对象

补了以下关键方法/属性：

| 属性/方法 | 补环境要点 |
|-----------|-----------|
| `createElement(tag)` | 返回带 `tagName`、`style`、`dataset`、`classList`、`setAttribute`/`getAttribute`、`appendChild` 等的伪 DOM 元素 |
| `createElement('canvas')` | 额外补 `toDataURL()`（返回固定 base64）、`getContext()` 返回伪 2D context（fillRect/fillText/measureText 等空实现） |
| `getElementsByTagName` | 对 `head`/`body` 返回对应伪元素 |
| `querySelector` / `querySelectorAll` | 返回 `null` / `[]` |
| `head` / `body` | 伪元素，支持 `appendChild`/`removeChild` |
| `documentElement` | 空 Proxy |
| `createEvent` | 空实现 |
| `cookie` | 硬编码初始值，运行时由 sign_wrapper.cjs 覆盖为真实 sessionid |

### 4. location 对象

完整模拟目标页面的 URL 信息：

```js
var location = createProxy('location', {
    href: "https://www.mashangpa.com/problem-detail/16/",
    origin: "https://www.mashangpa.com",
    protocol: "https:",
    host: "www.mashangpa.com",
    hostname: "www.mashangpa.com",
    pathname: "/problem-detail/16/",
    ...
});
```

### 5. navigator 对象

补了网站加密逻辑中会读取的所有属性：

| 属性 | 值 |
|------|-----|
| `userAgent` | Chrome 146 UA |
| `appVersion` | UA 去掉 `Mozilla/5.0` 前缀 |
| `platform` | `Win32` |
| `language` | `zh-CN` |
| `languages` | `["zh-CN", "zh"]` |
| `webdriver` | `false`（关键！必须为 false） |
| `hardwareConcurrency` | `12` |
| `plugins` | 5 个 PDF 相关插件（模拟 Chrome 默认插件列表） |
| `mimeTypes` | `application/pdf` + `text/pdf` |

同时用 `Object.defineProperty` 覆盖 Node.js 自带的 `globalThis.navigator`，防止 Sign 内部读到 Node 原生值。

### 6. plugins 模拟

精细模拟了 Chrome 的 `PluginArray`，包含 5 个 PDF 插件：

- PDF Viewer
- Chrome PDF Viewer
- Chromium PDF Viewer
- Microsoft Edge PDF Viewer
- WebKit built-in PDF

每个插件含 `name`/`description`/`filename`/`mimeTypes`，并实现了 `item()`/`namedItem()`/`refresh()` 方法。

### 7. 存储对象

`localStorage` 和 `sessionStorage` 均用内存对象模拟：

```js
var localStorage = createProxy('localStorage', {
    _data: {},
    getItem(key) { return this._data[key] || null; },
    setItem(key, value) { this._data[key] = String(value); },
    ...
});
```

### 8. screen 对象

```js
var screen = createProxy('screen', {
    width: 1920, height: 1080,
    availWidth: 1920, availHeight: 1040,
    colorDepth: 24, pixelDepth: 24,
});
```

### 9. XMLHttpRequest

空壳实现，仅打印日志，不实际发请求（Sign 内部可能会尝试创建 XHR 但不依赖其响应）。

### 10. 运行时参数注入（sign_wrapper.cjs）

sign_wrapper.cjs 在 eval 完 PcSign.js 后，**覆盖**上述默认值为运行时参数：

```js
// 注入 cookie
window.document.cookie = cookie;

// 注入浏览器环境（从 browser_env.json 读取）
window.navigator.userAgent      = env.userAgent;
window.navigator.platform       = env.platform;
window.navigator.language       = env.language;
window.screen.width             = env.screen.width;
window.devicePixelRatio         = env.devicePixelRatio;
// ...
```

支持通过 `envIndex` 参数切换不同指纹环境（Windows/Mac），实现指纹轮换。

## 补环境方法论总结

1. **Proxy 插桩** — 先用 Proxy 包装所有对象，运行一次，观察日志中访问了哪些属性
2. **按报错补齐** — 哪个属性报 `undefined`/`null` 就补哪个，优先补到不报错为止
3. **对比真实值** — 在真实浏览器 F12 中 `JSON.stringify` 导出对应属性值，粘贴到补环境代码中
4. **Canvas 特殊处理** — 返回固定 base64 图片数据，context 方法全部空实现
5. **参数外部化** — cookie、UA 等运行时变化的值不硬编码，通过 sign_wrapper.cjs 注入
6. **多指纹轮换** — browser_env.json 存放多套环境配置，降低被指纹识别的风险
