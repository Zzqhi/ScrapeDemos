## Handler 包装类型

| 包装函数 | 含义 |
|----------|------|
| `b()` | 基础 handler — 直接操作 VM 状态 |
| `TQ()` | 零参数 — 读取/求值，不消费操作数 |
| `OQ()` | 二元运算符 — 取两个操作数做运算 |
| `RQ()` | 属性访问 — 返回 `{T:值, J:obj, d:target, Y:key, F:keyName}` |
| `WQ()` | 块执行 — 遍历子节点列表执行 |
| `MQ()` | 方法调用 — 从栈读取参数调用 |
| `UQ()` | new 构造 — `new X(args...)` |
| `zQ()` | 函数定义 — 创建闭包并绑定作用域 |
| `kQ()` | 一元运算符 — 取一个操作数做运算 |
| `fQ()` | 循环 — for-in / while 等 |
| `BQ()` | 属性获取 — 简单 get |
| `EQ()` | 二元运算符（变体） |
| `AQ()` | 字面量 — 字符串等 |
| `GQ()` | 标识符引用 |
| `PQ()` | 标识符引用（最常用） |
| `FQ()` | 特殊运算 |

## VM 寄存器/状态

| 字段 | 含义 |
|------|------|
| `Q.h(n)` | 求值第 n 个子节点 |
| `Q.y(n)` | 读取第 n 个操作数的值 |
| `Q.E($)` | 解引用（取变量的值） |
| `Q.N($, v)` | 设值（给变量赋值） |
| `Q.o(Q.L[n])` | 执行第 n 个子指令 |
| `Q.V(Q)` | 求值（另一种方式） |
| `Q.L` | 子节点列表 (bytecode children) |
| `Q.K` | 操作数数量 / 子节点长度 |
| `Q.n.b` | 当前作用域 |
| `Q.n.b.b` | 局部变量表 |
| `Q.n.b.o` | 作用域栈 |
| `Q.t()` | 检查是否应中断执行 |
